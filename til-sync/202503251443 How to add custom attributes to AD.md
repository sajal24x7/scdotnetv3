## Pre-requisites
1. Make sure you have schema admin rights

## Steps
1. Go to mmc > active directory schema.
2. - In the **Active Directory Schema** administrative tool, do a right-click on **Attributes** and then select **Create Attribute…**
3. - Click on **Continue** (The warning that is displayed is to inform that the creation of a new Active Directory attribute is not a reversible operation and that it cannot be removed once done)
