1. Go to Dell support website
2. Provide your serial number and it will show relevant drivers.
3. Update OS.
4. Search for SUU, sort from descending date.
5. Download SUU ISO.
6. Also filter category by BIOS and idrac. 
	1. In case there are more recent versions available, download those as well.
7. Update BIOS and idRAC first. 
	1. Go to idrac page > Maintainance > Updates
	2. Upload the 2 .exe
	3. Then run it.
	4. Monitor the progress in the queue.
8. Go to Lifecycle manager, update firmware.
	1. Upload the SUU ISO
	2. It will show required upgrades
	3. Proceed with the install.
