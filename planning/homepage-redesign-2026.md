# Homepage Redesign — 2026 Brainstorming Notes

## Current structure

1. **Book hero** — cover image + description + buy/borrow links
2. **About + newsletter** — profile photo + bio + newsletter signup
3. **Featured** — 4 curated posts as dark image cards (shuffled from `homeFeatured.json`)

## Reference
