1. Open daily note - `Cmd+D`
2. Create unique note - `Cmd+Shift+Z`
3. Show file explorer - `Cmd+Shift+E`
4. Insert current date - `Cmd+Shift+D`
5. Close current tab/note - `Cmd+Shift+X`
6. Move note to different folder - `Cmd+M`
