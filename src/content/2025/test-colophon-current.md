## Current Site Stack

This website is built with modern web technologies:

- **Framework**: [Astro](https://astro.build) for static site generation
- **Styling**: [Tailwind CSS](https://tailwindcss.com) for utility-first styling
- **Content**: Markdown files with frontmatter for all content
- **Deployment**: [Netlify](https://netlify.com) for hosting and CI/CD

## Design Philosophy

The design focuses on readability, performance, and simplicity. Content is king, with minimal distractions and a clean, modern interface that adapts to both light and dark modes.

## Typography

- **Body text**: Inter for excellent readability
- **Headings**: Montserrat for visual hierarchy

The site is fully responsive and works seamlessly across all devices.
