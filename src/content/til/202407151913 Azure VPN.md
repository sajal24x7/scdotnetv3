# Types
- P2S VPN - Connects a specific device to a virtual network
- ﻿﻿S2S VPN - Connects a network to a virtual network
- ﻿﻿S2S VPN gateways enable multiple VPN connections to different networks if route not policy based

## High availability scenarios
1. Active/Standby
	1. Default 
	2. Automatic failover in case of issues or planned maintenance
2. Active/Active
	1. Get 2 [Public IP Address](/til/public-ip-address-allows-inbound-access-based-on-tier-in-azure)
	2. Uses BGP routing
3. [Express Route](/til/azure-expressroute) failover
	1. Gateway as secure failover for [Express Route](/til/azure-expressroute)
4. Zone-redundant gateways
	1. [Azure VPN](/til/azure-vpn) and [Express Route](/til/azure-expressroute) as zone-redundant deployments, where supported
