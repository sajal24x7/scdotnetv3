1. Download bundled installer from [Bundled installer](https://access.redhat.com/downloads/content/480)
2. Move the installer bundle to controller node.
3. Untar the setup.
```bash
tar zxvf ansible-automation-platform-setup-2.1.0-1.tar.gz
```
4. Change directory into untared folder.
5. Backup existing inventory file
```bash
cp inventory inventory.bkup
```
6. Install ansible core.
```bash
sudo dnf install ansible-core --assumeyes
```
7. Modify inventory file
