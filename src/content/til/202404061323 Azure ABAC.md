Part of [azure governance](/til/governance-overview)
Attribute based access control

# Why?
1. [RBAC](/til/azure-rbac) may not be granular enough or we start to hit [Azure RBAC#Limits](/azure-rbaclimits)
2. Adds conditions to roles assignments based on attributes of resources and principal accessing

# Where
Currently restricted to roles that have [blob storage or queue storage data actions](https://learn.microsoft.com/en-us/azure/role-based-access-control/conditions-format#actions).
# How to assign conditions
1. On user level, we could create and add custom attributes for users in ["Entra ID"](/til/entra-id)
2. In the role (in-built or custom) you can add a condition
