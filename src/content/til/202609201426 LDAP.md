Lightweight Directory Access Protocol. V3 but V2 included for backwards compatibility. It is open, vendor-neutral. LDAP is used to access and managed objects in a [Domain](/til/active-directory-domains).

We can use ldp tool to check the status/to troubleshoot, etc. Example - [How to check ldaps is working or not - ldp.exe](/til/how-to-check-ldaps-is-working-or-not-ldpexe).
