Part of [azure governance](/til/governance-overview)
Adjacent to [azure naming](/til/azure-naming)

1. name:value pair
2. identify attribute/metadata for resource
3. Have standards for tags used and values
4. Can enforce through [azure policy](/til/azure-policy)
	1. deny is scary
	2. better to tell if tag is not there, copy from resource group for example
5. Can be used for search, filter, and billing
6. not inherited but could be copied via [policy](/til/azure-policy)
	1. should be applied at [resources](/til/azure-resources) level for better visibility
	2. [resources](/til/azure-resources) don't inherit [tags](/til/azure-tagging) from [resource group](/til/resource-groups)
7. can be applied at [resource](/til/azure-resources), [resource group](/til/resource-groups) or [subscription](/til/azure-subscriptions) level
	1. not all [resources](/til/azure-resources) support tagging
8. [Azure Cost Management](/til/azure-cost-management) enables inheritance use only for billing usage records
