Static pods are managed by kubelet on a specific node, unlike regular [pods](/til/pods) which are managed by the control plane, based on files kept in the pod manifest directory. The kubelet scans the directory periodically and creates and deletes the pods based on if a file is added or removed. The kubelet also restarts the pod if it fails for example.

These are commonly used for control plane components.
