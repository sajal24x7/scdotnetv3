# Issues
## Cscript.exe is not recognised
1. Open regedit.
2. Go to HKCR\CLSID\{B54F3741-5B07-11cf-A4B0-00AA004A55E8}\InprocServer32
3. Within it, there is a registry value called (Default) which should carry a Data value of:
> C:\Windows\system32\vbscript.dll

If it's anything else, we need to change it to the above.
