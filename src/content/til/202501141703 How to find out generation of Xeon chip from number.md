**The first digit of the four-number sequence indicates the processor level**

| **Processor Level** |          |
| ------------------- | -------- |
| **8,9**             | Platinum |
| **6**               | Gold     |
| **5**               | Gold     |
| **4**               | Silver   |
| **3**               | Bronze   |

**The second digit indicates the processor generation**

| **Processor Generation** |                      |
| ------------------------ | -------------------- |
| **1**                    | 1st Gen Intel® Xeon® |
| **2**                    | 2nd Gen Intel® Xeon® |
| **3**                    | 3rd Gen Intel® Xeon® |
| **4**                    | 4th Gen Intel® Xeon® |
| **5**                    | 5th Gen Intel® Xeon® |
