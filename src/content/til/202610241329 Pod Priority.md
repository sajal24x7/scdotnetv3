Priority indicates the importance of a [pod](/til/pods) relative to others. 

For example, in use cases where you may want a infrastructure component to run before any other pod. 

As a different example, in a single cluster, you may want to give prod pods higher priority and then test environment and so on.

Another example would be when a certain service is required to run like DB or queue for the app to function. In that case you would want the DB to have a higher priority.
