Pods are the smallest unit of compute in [Kubernetes](/til/kubernetes).

Pods can contain one or more containers in them - usually one container. The additional containers can be helper containers. Containers in the same pod share resources like network, storage, etc.


```bash
# To get pods
kubectl get pods

# To run a a pod from an image
kubectl run nginx --image=nginx

```
