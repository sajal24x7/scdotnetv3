## Reproducible Developer Environments with Jumppad - Robert Barnes, HashiCorp

- used to use docker compose. There were issues though like low level dependencies, brittle bash scripts, health checks were manual, etc.
- They built [jumppad]([https://jumppad.dev](https://jumppad.dev/)) to solve these issues
- to run it you need - jumppad binary, git and docker or podman
- the demo was hashi specific but this can be used with k8s as well
- Will support pushing to cloud (shared dev environments)
- Not a hashi product, it’s open source
## Future of the Helsinki Hashicorp User Group meetup

Anoop talked about the history and future of this user group. They were sponsored by Hashicorp, but in Feb Hashicorp decided to not pay the fees for Meetup anymore. Which could turn out to be an opportunity. 

I think they should become a IaC meetup group and then they can invite other people who are doing IaC work as well. I think that's a good approach.
