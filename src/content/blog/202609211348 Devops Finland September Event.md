## How CRA affects today's agentic driven development by Ishani Bhardwaj and Berk Türetken, Consultants @ Netlight

![Talk 1](https://storage.sajalchoudhary.net/images/2026/09/devops-fin-sep-01.jpeg)

This talk was about CRA, which I did not know anything about before this. CRA is an EU Law that requires manufacturing companies to be responsible for vulnerabilities found in their products. The reporting for this lies with the orgs though and they could be fined 2.5% of global annual turnover, though there are lower tiers too.

There are four classes of products under it - basic, class 1, class 2, critical. There are stricter rules as you go up.

I learned something new, so was happy. The speakers felt new to the speaking game, and hence there were some little problems - which is fine tbh.

The problem is that most big orgs already have teams that do these sorts of tasks. I did not get what the takeaway of this talk, really.

## AWS Frontier Agents: How Agentic Al is Rewriting Cloud Operations by Sasidharan Ramasamy, Technical Account Manager @ AWS

![Talk 2](https://storage.sajalchoudhary.net/images/2026/09/devops-fin-sep-02.jpeg)

Sasi was up next and he came to talk about AWS Devops Agent service. The pitch, like the similar Azure agent I heard about in a FAUG event is the same - the agent will run the ops for you, all the time. You will not get pages at weird times.

There was a slide in the talk somewhere which talked about the types of orgs and from left to right it talked about orgs which were starting out with max human oversight to minimum oversight. The orgs on the right side (minimum oversight) were called pioneer orgs. 

I had a problem with that. Perhaps because I recently read [The Reverse Centaur’s Guide to Life After AI](/bookshelf/the-reverse-centaurs-guide-to-life-after-ai). Or, perhaps because the last talk talked about ownership and whose responsibility is it when AI agent pushes code with vulnerabilities in prod. Spoiler - it’s the org, it’s you. 

The problem is around ownership. The reverse centaur configuration makes sense to me. Where in I choose when and how I use the agents, not the other way around. Human in loop is a shit position to be in.

There was a time when talks like this would have me spellbound. Not. Any. More.

Philosophy aside, I liked the demo.
